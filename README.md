# VPN-бот: подписки, тарифы, админка

Telegram-бот продаёт доступ к VPN: **100 ₽/мес → 3 сервера, 200 ₽/мес → 6 серверов**.
Каждому клиенту выдаётся свой UUID и ссылка-подписка (открывается в Happ), по окончании срока доступ снимается автоматически.

## Что внутри

| Файл | Зачем |
|---|---|
| `bot.py` | сам бот + сервер подписок + админ-панель |
| `servers.example.json` | 9 твоих серверов (скопировать в `servers.json`) |
| `.env.example` | переменные (скопировать в `.env`) |
| `Dockerfile`, `docker-compose.yml`, `Caddyfile` | запуск одной командой + HTTPS |
| `test_bot.py` | автотесты (29 проверок) |
| `data/` | сюда пишется база `vpn.db` (volume) |
| `ssh/` | сюда кладётся приватный SSH-ключ `vpnbot` |

## Быстрый старт (Docker)

```bash
# 1. SSH-ключ, по которому бот заходит на VPN-серверы
ssh-keygen -t ed25519 -f ssh/vpnbot -N ""
for ip in 2.26.129.81 2.26.130.159 2.26.135.239 2.26.139.204 152.232.57.100 2.26.128.99; do
  ssh-copy-id -i ssh/vpnbot.pub root@$ip
done

# 2. настройки
cp .env.example .env                      # впиши BOT_TOKEN, ADMIN_ID, BASE_URL
cp servers.example.json servers.json
# в Caddyfile замени sub.example.com на свой домен

# 3. запуск
docker compose up -d --build
docker compose logs -f bot
```

Затем в Telegram: `/start` у бота, `/admin` у тебя (только с аккаунта `ADMIN_ID`).

### Платформа без compose (Coolify, Dokploy, Railway, Portainer и т.п.)

Файлы `servers.json` и ключ в образ не входят, поэтому передай их переменными окружения:

```bash
base64 -w0 servers.json   # → значение SERVERS_JSON
base64 -w0 ssh/vpnbot     # → значение SSH_KEY_B64
```

И подключи **один volume**: путь внутри контейнера `/data`, плюс переменная `DB_PATH=/data/vpn.db`.
Порт приложения: 8080 (на него смотрит домен/прокси платформы, Caddy в этом случае не нужен).

Без `SERVERS_JSON` бот остановится с понятной ошибкой, а не с трейсбеком.

### Без Docker

```bash
pip install -r requirements.txt
cp .env.example .env && cp servers.example.json servers.json
# в servers.json замени "ssh_key": "/keys/vpnbot" на путь к своему ключу, например /root/.ssh/vpnbot
python bot.py
```
HTTPS перед портом 8080 поставь сам (Caddy/nginx).

## База данных и volume

- **Внешняя БД не нужна.** Бот использует SQLite: один файл `vpn.db` (клиенты, сроки, оплаты). Для сотен клиентов этого хватает с запасом.
- **Volume нужен, и только один: `/data`** (серверы и ключ можно передать переменными). В контейнере файловая система временная: без volume база пропадёт при пересборке и все клиенты потеряются (а их UUID на серверах останутся, но бот о них забудет). В `docker-compose.yml` уже стоит `./data:/data`, так что делать ничего не надо.
- Если запускаешь на платформе вроде Railway/Render/Fly: смонтируй постоянный диск на `/data` и задай `DB_PATH=/data/vpn.db`.
- **Бэкап** = копия одного файла:
  ```bash
  cp data/vpn.db backup/vpn-$(date +%F).db
  ```
  (можно повесить на cron раз в день).
- Тот же принцип у Caddy: volume `caddy_data` хранит сертификаты.

## Важно про серверы

- Порядок в `servers.json` важен: **первые 3** получают клиенты за 100 ₽, **первые 6** клиенты за 200 ₽. Серверы 7-9 сейчас никому не выдаются. Это резерв: если захочешь поднять тариф, поменяй `PLANS` в `bot.py`.
- Бот правит `/usr/local/etc/xray/config.json` по SSH и перезапускает Xray (подключения на этом сервере рвутся примерно на секунду). Если у сервера другой путь или несколько VLESS-inbound'ов, укажи `config_path` и `inbound_tag` в `servers.json`.
- Клиенты бота помечаются в конфиге `email: tg_<id>`. Клиенты без такой метки (твой старый общий UUID `bcd508e0-...`) бот не трогает: удали его вручную, когда клиенты перейдут на подписки.
- **Не запускай Caddy на сервере, где Xray уже занял порт 443.** Бот с Caddy лучше держать на отдельной маленькой VPS.
- Если домена нет, сделай бесплатный поддомен на duckdns.org, указывающий на IP этой VPS.

## Команды админа

| Команда | Что делает |
|---|---|
| `/admin` | панель: статистика, клиенты, синхронизация серверов |
| `/user <id или @username>` | карточка клиента |
| `/grant <id> <100\|200> [дней]` | выдать доступ без записи оплаты (подарок/тест) |
| `/revoke <id>` | отключить клиента |
| `/broadcast <текст>` | написать всем активным клиентам |

Оплата: клиент платит тебе в личку, нажимает «Я оплатил», тебе приходит заявка с кнопками «Подтвердить / Отклонить».
